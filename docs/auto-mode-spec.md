# 答题模式 · 自动模式 需求文档

> 状态：**已实现（v2.7，2026-09-12）**。本文档保留为功能规格说明。
> 适用范围：仅答题模式（截屏识别），不涉及面试模式

---

## 1. 背景与目标

笔试/网课刷题场景下，目前每做一道题都要手动点「识别本题」或按快捷键。
对"题目会定时/分批刷新"的页面（如限时笔试每题倒计时自动跳转），
用户希望工具能**周期性地自动识别当前屏幕上的题目**，
题目没变就不打扰，题目变了就自动给出新答案。

**非目标**（明确不做）：

- 不做自动点击选项、不做自动翻页（旧版"自动模式"的连答能力不恢复）
- 不影响面试模式的任何行为

## 2. 现有代码盘点（实现时可复用/需注意的部分）

| 资产 | 位置 | 与新需求的关系 |
| --- | --- | --- |

## 3. 功能需求

### 3.1 前置条件

- 自动模式**必须先框选题目区域**。
- 未框选时点击「自动」按钮：按钮不进入激活状态，状态栏提示
  "请先框选题目区域"（与现有 `recognize_now` 的提示一致），
  并引导用户完成框选（可直接弹出框选，与手动识别行为对齐）。

### 3.2 按钮与生效范围

- 主窗口操作区新增「🤖 自动： 关 / 开」切换按钮，**仅对答题模式生效**。
- 用户切换到**面试模式**（或未来的其他模式）时，自动模式**立即退出**：
  按钮弹起、定时器停止、状态栏提示"已切换到面试模式，自动模式已停止"。
- 自动模式激活状态**不持久化**：退出程序后再次打开默认关闭。

### 3.3 周期识别

- 激活后，**每 30 秒**自动执行一次与「识别本题」等效的流程
  （截图 → 多模态识别 → 显示答案）。
- 周期从**激活时刻**起算；上一轮识别仍在进行（inflight）时，
  本轮直接跳过，不排队、不并发。
- 手动「识别本题」按钮与快捷键在自动模式激活期间**依然可用**，
  手动触发不重置 30 秒计时器（避免用户行为被计时器干扰）。

### 3.4 题目去重（混合判重，v2.7.1 起）

每轮触发时先本地粗筛、再由模型仲裁，两级判重：

1. **指纹粗筛（零成本）**：截取框选区域，与基线指纹比对
   （`fingerprint()` 64×64 灰度，差异率阈值 3%）。未变 → 不调用模型、
   不动答案区，状态栏轻提示"题目未变化，已跳过"。
2. **双图仲裁（指纹变了才触发）**：把上一题基线截图 + 本次截图一起发给
   模型，判重规则前置在提示词中：同一题（倒计时/进度条/动画等动态元素
   不算换题）只回复 `SAME`；不同题正常作答。
   - 回复 `SAME` → 答案区**恢复旧答案**（不被"识别中"冲刷），
     基线帧刷新为本次截图（跟住倒计时缓慢漂移）；
   - 正常答案 → 答案区整体替换，基线帧更新。
3. 失败回滚：识别失败不确立基线（指纹回滚），下一轮正常重试；
   重新框选 / Ctrl+Alt+C 清空时，指纹与基线帧一并重置。

### 3.5 错误处理

- 单次识别失败（网络/模型错误）：**不退出自动模式**，状态栏显示失败原因，
  下一轮照常触发。
- 截图失败（区域失效等）：**自动停止自动模式**并提示用户重新框选。
- 连续失败兜底：连续 3 次识别失败 → 自动停止并提示
  "连续识别失败，自动模式已停止，请检查模型配置"。

## 4. 界面与状态反馈

- 按钮文本：`🤖 自动: 关` ↔ `🤖 自动: 开`，遵循透明模式/emoji 剥离等
  现有 UI 规则（与「识别本题」按钮同等对待）。
- 激活期间状态栏常驻轻提示（如"自动模式： xx 秒后下一轮 / 识别中…"），
  不刷屏。
- 答案区规则与手动识别完全一致：新题替换显示，未变不动。

## 5. 上下文组织设计（答题模式引入轻量状态）

当前答题模式完全无状态，自动模式需要引入**最小题目状态**：

```
_quiz_state = {
    "fingerprint": bytes | None,   # 最近一次题目区域截图指纹（粗筛基线）
    "baseline_png": bytes | None,  # 最近一次成功作答的题目截图（双图仲裁用）
    "asked_at":    datetime | None # 最近一次实际调用模型的时刻
}
```

- **指纹不变不发送**：粗筛在本地完成，零成本；**指纹变了才双图仲裁**，
  模型判"同一题"只回 `SAME`（1 个 token），避免倒计时等动态噪声
  导致答案区每轮闪烁重答。模型调用次数 ≈ 换题次数 + 含动态噪声的轮次。
- **不积累历史**：题目之间不建立上下文链（选择题之间无依赖，
  旧题上下文只会稀释提示词）。每次识别仍是单轮请求，
  提示词沿用当前答题预设的 `prompt`（判重规则为固定前缀，不动预设提示词）。
- 手动「清空答案区」（Ctrl+Alt+C）时同步清空指纹与基线帧，
  下一轮自动触发将视为新题重新识别。

## 6. 边界情况清单

| 场景 | 预期行为 |
| --- | --- |
| 激活中切换到面试模式 | 自动模式立即停止并弹起按钮 |
| 激活中重新框选区域 | 沿用新区域继续轮询，指纹基线重置 |
| 激活中切换模型预设 | 不中断，下一轮用新预设 |
| 窗口最小化到托盘 | 自动模式暂停；恢复窗口后继续（见 §7 D2） |
| 屏幕分辨率/多屏变化导致区域失效 | 截图失败 → 自动停止并提示重新框选 |
| 程序退出 | 自动模式不持久化，下次启动默认关 |

## 7. 决策结果（2026-09-12 用户已确认）

- **D1 轮询间隔**：在「设置 · 答题模型」页提供**可调间隔选项**
  （默认 30 秒，随预设保存）。
- **D2 托盘态行为**：窗口收进托盘后自动模式**暂停**；
  从托盘恢复窗口后若按钮仍处于激活态则继续轮询。
- **D3 未变提示强度**：**每次都轻提示**（状态栏"题目未变化，已跳过"），
  但提示更新**必须确保隐身**——状态栏文本变化不得引起任何
  窗口重建/重显，遵守"先设隐身、再显示"的全生命周期约束（v2.6.2 起）。
- **D4 激活即识别**：点击「自动」开启时**立即识别一次**当前题，
  随后进入 30 秒（或设定间隔）周期。
