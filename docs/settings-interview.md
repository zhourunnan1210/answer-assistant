# 设置 · 面试助手

> 路径：主窗口右上角「⚙ 设置」→ 左侧「面试助手」
>
> 面试辅助 = **双通道监听（面试官 + 你）+ 个人资料库**。
> 多轮追问也能跟上上下文：知道在聊哪个项目、你刚才已经说过什么，
> 生成的回答贴合你的真实经历、可直接照着念。

![面试助手设置](images/settings_interview.png)

---

## 使用前提：信息初始化（面试前做一次）

按 ① → ② → ③ 顺序完成，一次配置长期有效。

### ① 原始资料

- **上传资料…**：简历、项目说明、个人总结等，支持 PDF / Word(.docx) / TXT / Markdown，可多选
- 只提取文字内容；原文件备份在 `%LOCALAPPDATA%\答题助手\profile\raw\` 下，可随时追溯
- **清空**：删除全部已上传资料

### ② 固定文稿

你的"标准答案库"：个人介绍 + 过往项目介绍，每次回答都会全文带上。

- **AI 生成/重新生成**：LLM 把原始资料整理成固定文稿
  （个人介绍 150 字内口语化、每段项目含角色/时间/技术栈/可量化成果、技能清单）
- **✏ 编辑 / 👁 预览**：在类 Typora 的 Markdown 编辑器窗口中修改或查看
  （编辑 / 预览 / 分屏三种视图）——**AI 生成后建议通读改一遍，加入你自己的表达习惯**
- **从文件导入…**：直接使用自己写好的 Markdown 文稿

### ③ 灵活文稿

面试追问的"弹药库"：3~8 篇专题文稿，每篇聚焦一个主题
（某项目的技术细节、遇到的关键问题与解决、核心技术的深入理解、团队协作等）。

- **AI 生成/重新生成**：基于固定文稿 + 原始资料生成，每篇带 5~8 个关键词
- 面试时根据面试官的问题**本地检索命中**最相关的 1~2 篇注入上下文，
  保证细节问题有据可依
- 双击列表项（或选中后点「编辑选中」）在 Markdown 编辑器中逐篇修改；
  「删除选中」可去掉质量差的篇目

> **上下文是怎么组装的**（每次自动作答时发送给模型）：
> 面试提示词 + 复盘改进要点 + 固定文稿全文 + 灵活文稿索引 + 命中的专题全文
> + 面试对话记录 + 面试复盘要点 + 面试官最新讲话。

## 面试进行中

主窗口点「💼 面试」开启（自动带动「🎙 问答」）：

- **双通道监听**：扬声器里的面试官（灰色「听到：…」）+ 麦克风里的你
- 你的讲话在答案区只显示一行「我：( 正在说话 )」轻量指示防刷屏；
  内容本身完整记入对话上下文——**连续碎段自动合并为一条**（v2.0），记录干净易读
- **内置防噪**：语气词/杂音碎片自动过滤；扬声器外放造成的麦克风回声自动剔除；
  模型因噪音误判"听不清"时，自动改用上一个完整问题重试一次
- 每次作答前答案区自动清空，只保留**当前问题 + 回答**，生成完直接照着念

### 自动作答（默认开启，推荐）

- 面试官停止讲话 **3 秒**后自动整理上下文生成回答；
  若最后一句像没说完（句末没有完整标点），自动放宽到 **4 秒**
- 期间面试官继续讲话会重新计时；回答生成中来了新内容也会自动跟进
- 取消勾选则改回手动模式：按 `Ctrl+Alt+W` 或点「💬 回答」触发

### 面试提示词

面试模式专用提示词（随预设保存/切换）。默认已包含：
结合对话记录定位当前在聊哪个项目、第一句话直接回应、引用文稿中的真实细节、
与已说过的内容连贯不矛盾、口语化 200 字以内、不编造、噪音碎片不答"听不清"、
朗读/操作类环节给指引不编造、回答语言跟随提问语言。

## 面试结束后：资料库持续优化（④ 面试复盘）

由「通用 → 持续优化」开关控制（默认开启）。

1. **自动保存**：关闭面试模式或**以任何方式退出程序**（含 Alt+F4 / 任务栏关闭 /
   系统关机）时，本场完整记录自动保存到 `profile/sessions/时间戳.md`，
   并调用 LLM 生成面试复盘（问题清单归类 + 回答质量点评 + 资料补充建议）
2. **复盘存储**：`interview_review.md` 始终是最新一场（供注入上下文），
   历史复盘按时间戳归档在 `reviews/` 目录；「✏ 编辑复盘 / 👁 预览复盘」
   可在 Markdown 编辑器中查看修改
3. **✨ 一键优化资料库**：按复盘的「资料补充建议」自动更新/新增灵活文稿，
   并给出宏观回答结构建议（如分点数量、STAR 结构）——
   预览确认后才生效，生效前自动备份原灵活文稿为 `.bak`；
   提示词改进与现有要点**智能合并**（非覆盖），用户级配置不随预设切换
4. **复盘注入**（默认开启）：后续面试的上下文附带复盘要点（上限 1500 字），
   模型知道"哪些问题被问过、上次答得如何"，越面越准

## 数据与隐私

- 资料库全部存放在本机 `%LOCALAPPDATA%\答题助手\profile\`，不会随源码上传，
  只在生成回答时随问题发给你自己配置的 LLM
- 资料库、复盘、提示词改进是**用户级**数据，切换供应商预设不影响
- 对话上下文保存在内存中，退出即清空；落盘的场次记录属于你主动保留的资料库资产

## 常见问题

**Q：回答感觉很慢？**
检查「通用 → 实时思考」是否被打开（默认关）；另外回答模型本身的速度是关键，
面试建议用响应快的模型。

**Q：面试中我说了很多，为什么回答没跟上我说的？**
你的讲话 2 秒合并后才进上下文；刚说完立刻触发的回答可能只包含部分口述。
正常追问节奏下上下文是完整的。

**Q：换电脑/重装后资料库还在吗？**
在。资料库存放在 `%LOCALAPPDATA%\答题助手\profile\` 稳定目录，
重装/升级不会清除；换新电脑时复制该目录即可迁移。
