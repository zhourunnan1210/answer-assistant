# 设置 · 通用

> 路径：主窗口右上角「⚙ 设置」→ 左侧「通用」
>
> 这一页是**外观、快捷键与全局行为**设置。所有项都是用户级配置，
> 不随供应商预设切换。

---

## 识别快捷键

触发「识别本题」的全局快捷键，可选 `Ctrl+Alt+Q`（默认）/ `Ctrl+Alt+A` / `F9` / `F10`。

浏览器全屏刷题时的核心用法：先框选好题目区域，之后每题直接按快捷键，
无需切出浏览器、无需点本工具窗口——页面不会检测到焦点离开。

固定快捷键（不可改）：

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+Alt+S` | 顺序切换预设（切换后自动测试连接） |
| `Ctrl+Alt+C` | 清空答案区，恢复快捷键提示 |
| `Ctrl+Alt+W` | 问答/面试模式下：把识别到的讲话内容发给模型生成回答 |

## 答案字号

答案区文字大小，10~28 px（默认 14）。答案区以 Markdown 渲染显示。

## 窗口不透明度

整个窗口的不透明度 50%~100%（含文字一起淡出）。默认 92%。

## UI 区域背景 / 答案区背景

- **UI 区域背景**：标题栏、按钮区底板的不透明度 0~100%（只影响背景，文字保持清晰）
- **答案区背景**：答案显示区背景的不透明度 0~100%

两个滑杆配合可以调出"按钮区实、答案区近乎全透"等效果，
在全屏刷题时把窗口的存在感降到最低。

## 沉浸式模式（问答/面试时）

开启后，在问答/面试模式运行期间：

- 鼠标**移入答案区** → 显示完整界面（标题栏、按钮都回来）
- 鼠标**完全离开窗口** → 自动隐藏标题栏和按钮，只保留答案区
- 鼠标在窗口内其他按钮上时**不会隐藏**，放心点击

适合面试/会议中把窗口缩成一条"提词器"。

## 实时思考

**问答/面试专用**的思考模式开关，默认**关闭**。

- 问答/面试是实时场景：面试官问完话，你每多等一秒都尴尬，
  所以默认关闭思考以压低延迟
- 开启后回答可能更深入，但会多出数秒至十几秒的思考时间
- 答题、面试复盘、资料库生成等"不赶时间"的任务不受此开关影响，
  仍使用「答题模型」页的思考模式开关

## 兼容隐身（Windows 10 2004，需重启）

主窗口默认通过 `WDA_EXCLUDEFROMCAPTURE` 对屏幕共享/录屏**隐身**
（网页发起"共享屏幕"时看不到本窗口）。要求 Windows 10 2004（build 19041）及以上。

Win10 2004 等旧系统上，半透明分层窗口会导致隐身失效
（共享画面中窗口可见或出现黑块）。开启本项并重启后，
主窗口禁用半透明背景与整体透明度，改用普通不透明窗口以保证隐身生效。

- Win10 21H2 / Win11 全系列：**无需开启**
- Win10 2004 且发现隐身失效：开启 + 重启；同时建议打满 Windows Update

## 持续优化

面试结束后自动保存本场记录到资料库 `sessions/` 目录并生成面试复盘
（新问题归类 + 回答点评 + 资料补充建议）。详见
[设置 · 面试助手](settings-interview.md#面试结束后资料库持续优化-面试复盘)。

## 窗口行为备忘（无需设置）

| 行为 | 说明 |
| --- | --- |
| 置顶 | 标题栏「📌」切换窗口是否始终置顶（默认置顶） |
| 最小化 | 标题栏「—」收进系统托盘；点托盘图标或双击恢复主窗口 |
| 调整大小 | 拖动窗口边缘/角落即可，尺寸自动记忆 |
| 框选区域 | 「▣ 框选区域」拖选一次即记住；再次点击「取消框选」可清除 |
| 不抢焦点 | 窗口永远不会从浏览器抢走键盘焦点，点击窗口内按钮不会触发网页的"切出检测" |
| 退出保存 | 任何方式退出（X / 托盘退出 / Alt+F4 / 任务栏关闭 / 系统关机）都会先保存进行中的面试记录 |

## 数据存放位置

| 内容 | 位置 |
| --- | --- |
| 全部设置 | `%LOCALAPPDATA%\答题助手\config.json` |
| 个人资料库（文稿/复盘/场次记录） | `%LOCALAPPDATA%\答题助手\profile\` |

均在本机，重装/升级不丢失；换机迁移复制整个 `答题助手` 目录即可。
